# Umbrel Community App Store – lbrozovsky

Přidání do Umbrelu: **App Store → ⋯ (vpravo nahoře) → Community App Stores**,
vložit adresu tohoto repozitáře:

```
https://github.com/lbrozovsky/umbrel-apps
```

## Aplikace

- **GMaps Tracker** (`lbrozovsky-gmaps-tracker`) – historie poloh ze Sdílení
  polohy v Google Maps. Zdrojový kód: <https://github.com/lbrozovsky/gmaps-tracker>

Po instalaci nahrajte aplikací **Files** do složky aplikace, podsložky `data`,
soubor `cookies.txt` (a případně `locations.sqlite` s dosavadní historií).
